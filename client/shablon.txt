# Գաղտնիության քաղաքականություն

## 1. Ընդհանուր տեղեկություն

Այս կայքը ուսումնական վեբ նախագիծ է, որը ստեղծվել է վեբ ծրագրավորման հմտությունները ցուցադրելու և ժամանակակից վեբ տեխնոլոգիաների կիրառումը ներկայացնելու նպատակով։

Կայքի օգտագործման ընթացքում կարող են օգտագործվել օգտատիրոջ կողմից տրամադրված որոշ տվյալներ՝ կայքի հիմնական ֆունկցիոնալությունն ապահովելու համար։

## 2. Ինչ տվյալներ են օգտագործվում

Կայքում կարող են օգտագործվել հետևյալ տվյալները

* Օգտանուն
* Էլ․ փոստի հասցե
* Գաղտնաբառ
* Օգտատիրոջ պրոֆիլի տվյալներ
* Ծանուցումների հետ կապված տվյալներ

## 3. Ինչ նպատակով են օգտագործվում տվյալները

Տվյալներն օգտագործվում են կայքի հետևյալ հնարավորություններն ապահովելու համար.

* Օգտատիրոջ գրանցում
* Մուտք գործել հաշիվ
* Օգտատիրոջ նույնականացում
* Պրոֆիլի տվյալների փոփոխություն
* Գաղտնաբառի փոփոխություն
* Ծանուցումների տրամադրում
* Օգտատիրոջ հաշվի կառավարում

## 4. Տվյալների անվտանգություն

Օգտատիրոջ գաղտնաբառերը չեն պահվում բաց տեքստով։ Գաղտնաբառերը պահպանվում են hashավորված տեսքով՝ օգտագործելով bcrypt տեխնոլոգիան։

Նույնականացման համար օգտագործվում են access token և refresh token մեխանիզմները։

## 5. Local Storage

Կայքը կարող է օգտագործել browser-ի Local Storage-ը՝ նույնականացման և օգտատիրոջ հիմնական տվյալների պահպանման համար։

Local Storage-ում կարող են պահպանվել՝

* accessToken
* refreshToken
* օգտատիրոջ հիմնական տվյալներ
* կայքի որոշ նախընտրություններ

## 6. Օգտատիրոջ հաշվի ջնջում

Օգտատերը կարող է ջնջել իր հաշիվը Settings բաժնի միջոցով։

Հաշվի ջնջման դեպքում համապատասխան օգտատիրոջ տվյալները կարող են հեռացվել նախագծի տվյալների բազայից։

## 7. Ուսումնական նախագծի բնույթը

Այս կայքը ստեղծվել է բացառապես ուսումնական նպատակներով։

Կայքի միջոցով հավաքվող կամ օգտագործվող տվյալները նախատեսված են նախագծի ֆունկցիոնալությունը ցուցադրելու և վեբ ծրագրավորման տեխնոլոգիաների կիրառումը ներկայացնելու համար։

## 8. Գաղտնիության քաղաքականության փոփոխություններ

Այս էջի բովանդակությունը կարող է փոփոխվել նախագծի զարգացման ընթացքում։

Փոփոխությունների դեպքում թարմացված տարբերակը կտեղադրվի այս էջում։

## 9. Կապ

Նախագծի կամ տվյալների օգտագործման վերաբերյալ հարցերի դեպքում կարող եք կապ հաստատել կայքի հեղինակի հետ։












# Политика конфиденциальности

## 1. О сайте

Данный сайт представляет собой учебный веб-проект на тему путешествий, созданный для представления информации о путешествиях, интересных местах, еде и вариантах отдыха.

Сайт включает несколько основных разделов — **Travel, Food и Relax**, где пользователи могут знакомиться с различными местами, идеями для путешествий, блюдами и вариантами отдыха.

Проект создан с целью демонстрации навыков веб-разработки и практического применения современных веб-технологий. Функциональность сайта включает регистрацию и авторизацию пользователей, управление профилем, уведомления, просмотр публикаций и другие интерактивные возможности.

## 2. Какие данные используются

Для работы некоторых функций сайта могут использоваться следующие данные:

* Имя пользователя
* Адрес электронной почты
* Пароль
* Данные профиля пользователя
* Данные уведомлений

Эти данные используются преимущественно для работы пользовательского аккаунта и персонализированных функций сайта.

## 3. Для чего используются данные

Данные пользователя используются для обеспечения следующих возможностей:

* Регистрация и авторизация
* Идентификация пользователя
* Управление личным профилем
* Изменение данных профиля
* Изменение пароля
* Получение уведомлений
* Управление пользовательским аккаунтом

Информационный и туристический контент сайта может быть доступен без регистрации.

## 4. Безопасность данных

Пароли пользователей не хранятся в открытом виде. Они сохраняются в хешированном виде с использованием технологии **bcrypt**.

Для идентификации и авторизации пользователей используются механизмы access token и refresh token.

## 5. Local Storage

Сайт использует Local Storage браузера для хранения информации, необходимой для авторизации пользователя и сохранения некоторых настроек.

В Local Storage могут сохраняться:

* accessToken
* refreshToken
* основные данные пользователя
* некоторые настройки сайта

## 6. Управление аккаунтом

Зарегистрированный пользователь может управлять своим профилем через раздел Settings.

Пользователь может изменить личные данные, изменить пароль, выйти из аккаунта или удалить свою учетную запись.

## 7. Учебный характер проекта

Данный сайт создан **исключительно в учебных целях**.

Он является примером веб-проекта на туристическую тематику и предназначен для демонстрации навыков frontend и backend-разработки, работы с базами данных, аутентификацией и другими современными веб-технологиями.

Сайт не является туристическим агентством, системой бронирования или платным сервисом.

## 8. Изменения политики конфиденциальности

Поскольку проект может продолжать развиваться, содержание данной страницы также может изменяться.

В случае внесения изменений обновлённая версия будет опубликована на этой странице.

## 9. Контакты

Если у вас есть вопросы относительно проекта, его функциональности или использования данных, вы можете связаться с автором сайта.
















# Privacy Policy

## 1. About the Website

This website is an educational web project focused on travel and created to present information about destinations, interesting places, food, and relaxation options.

The website includes several main sections — **Travel, Food, and Relax**, where users can explore different destinations, travel ideas, food-related content, and places or activities for relaxation.

## 2. What Data Is Used

Certain website features may use the following information:

* Username
* Email address
* Password
* User profile information
* Notification-related data

This information is primarily used to provide user account functionality and personalized features.

## 3. How the Data Is Used

User data is used to provide the following features:

* User registration and authentication
* User identification
* Personal profile management
* Profile information updates
* Password changes
* Notifications
* User account management

The travel and informational content of the website may also be available without creating an account.

## 4. Data Security

User passwords are not stored in plain text. They are stored in hashed form using **bcrypt** technology.

Access token and refresh token mechanisms are used for user authentication and identification.

## 5. Local Storage

The website uses the browser's Local Storage to store information required for user authentication and certain website preferences.

The following information may be stored in Local Storage:

* accessToken
* refreshToken
* Basic user information
* Certain website preferences

## 6. Account Management

Registered users can manage their profile through the Settings section.

Users can update their personal information, change their password, log out, or delete their account.

## 7. Educational Purpose

This website has been created **exclusively for educational purposes**.

The website is not a travel agency, booking platform, or paid service.

If changes are made, the updated version will be published on this page.
